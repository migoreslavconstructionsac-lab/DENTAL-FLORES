# DENTAL FLORES · Página web

Versión preparada para GitHub Pages. La carpeta raíz contiene `index.html`, `styles.css`, `scripts.js` y `assets/`.

## Instalación

1. Crea un repositorio **nuevo** llamado `dental-flores` en GitHub; no reemplaces el repositorio de ingeniería.
2. Descomprime el ZIP y sube **el contenido** a la raíz del repositorio, no el ZIP.
3. Ve a Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.
4. Abre la URL que GitHub Pages muestre al publicar.

## Contenido provisional que debes validar antes de la publicación pública

- Fotografías generadas con IA: no son fotografías reales de la doctora ni del consultorio. Sustituir por imágenes autorizadas, manteniendo el aviso hasta entonces.
- Colegiatura COP y RNE: no se inventaron. Añadir los datos auténticos tras verificarlos.
- Corroborar los tratamientos realmente prestados, disponibilidad y días de atención.
- Horario indicado: 8:00 a. m. – 8:00 p. m.; días sujetos a confirmación por WhatsApp.
- Redes sociales: aparecen como **Próximamente** sin enlaces inventados.
- Ubicación de Google Maps: es una búsqueda por dirección y puede necesitar ajuste del pin exacto.
